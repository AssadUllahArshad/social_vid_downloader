# First 500 brief decisions

All 500 original candidates are processed: 66 published supporting articles (20 existing and 46 added), 434 consolidated, zero unresolved. No replacement topics or second batch were created. Archived candidate URLs were never public; they return 404 rather than redirecting or becoming duplicate pages.

Primary official documentation and current product behavior were used to test whether each problem requires a different answer. Repeated platform/browser/device combinations were compared by their actual workflow. No keyword volume, traffic forecast, ranking result, or fresh live-provider success is asserted. Each approved intent has an individually authored answer and cited sources in the canonical article store.

The original 400 scoped candidates repeat 50 topics across eight media types. Where the diagnostic or file behavior is shared, one canonical answer owns the facet. Provider-specific link guides and failure guides retain genuinely different source behavior. The other 100 general candidates were similarly clustered by the outcome a reader needs. Consolidation applies the user-benefit rule; 66 is the result of review, not a numerical publication cap.
